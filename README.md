# Marketing Campaign Analysis

## 📌 Project Overview

This project analyzes marketing campaign data using Python, Pandas, and Matplotlib to evaluate campaign performance and identify useful business insights.

The analysis focuses on marketing channels, campaign types, target audiences, revenue generation, conversion efficiency, and return on advertising spend (ROAS).

This is a practice dataset created for learning and portfolio development.

---

## 🎯 Objectives

- Analyze marketing campaign performance
- Compare different marketing channels
- Evaluate campaign types
- Analyze target audience performance
- Calculate CTR and conversion rate
- Calculate ROAS
- Analyze marketing spend and revenue
- Calculate cost per conversion
- Identify useful business patterns through data analysis and visualization

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV
- Data Analysis
- Data Visualization
